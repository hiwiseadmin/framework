口径说明：本页数据来自 match3_pvp_player.is_cheat，来源分三类：
① 人工复核（manual_review）—— 运营确认后写的标记；
② score_over_replay —— PHP 重放引擎（replay_engine.mode = php）算出"这一局最多能得多少分"， 若玩家上报分数超过该上界 × (1+容差) 则标记可疑。 ⚠️ 当前 compare_mode = upper_bound + upper_bound_action = flag： 只标记、不拦截、不改分（观察期），用于积累两端口径偏差数据；
③ result_mismatch / board_mismatch —— 只有在 compare_mode = strict（口径已对齐）或 replay_engine.mode = http（Node 同源引擎）时才会产生， 当前不会自动出现。
L1/L2 独立拦截的还有 invalid_op（交换不相邻 / 跨 region / 移动锁定格 / 超步数） 与 invalid_claim（分数超理论上限 / 步数超限 / goals 结构非法）。
