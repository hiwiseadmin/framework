介绍

优化版 Clipboard.js 是一个现代化的剪贴板操作库，解决了原生 clipboard.js 在某些浏览器中全选复制时出现的系统提示框问题。

本库使用 Range API 替代全选操作，避免触发浏览器的复制提示框，提供更流畅的用户体验。同时优先使用现代浏览器原生的 Clipboard API，提供更好的性能和安全性。

注意： 由于安全限制，某些剪贴板操作需要在安全上下文（HTTPS）中才能正常工作。
主要优势
  • 避免全选复制提示框
  • 支持现代 Clipboard API
  • 完整的事件系统
  • Bootstrap 5 友好
  • 无障碍支持
  • 轻量级设计

安装 

npm install clipboard
// ES6 导入
import Clipboard from 'clipboard';

// 或 CommonJS
const Clipboard = require('clipboard');
<!-- 通过 CDN 引入 -->
<script src="https://cdn.jsdelivr.net/npm/clipboard@1.0.0/dist/clipboard.min.js"></script>

引入后，库将作为全局变量 Clipboard 可用。

从 GitHub 仓库下载最新版本，或直接复制下面的源代码到你的项目中。 
// 将完整的 UMD 版本代码保存为 clipboard.js
// 然后通过 script 标签引入
<script src="path/to/clipboard.js"></script>

使用示例

基本复制

复制指定的文本内容，最简单直接的方式。

点击复制按钮，然后粘贴到其他位置测试效果。 
// HTML
<input type="text" value="这是一个要复制的基本文本示例" readonly>
<button class="clipboard-btn" data-clipboard-text="这是一个要复制的基本文本示例">
    <i class="bi bi-clipboard"></i> 复制
</button>

// JavaScript
const clipboard = new Clipboard('.clipboard-btn');

clipboard.on('success', function(e) {
    console.log('复制成功:', e.text);
    e.trigger.classList.add('copied');
});

clipboard.on('error', function(e) {
    console.error('复制失败:', e.error);
});
// HTML <input type="text" value="这是一个要复制的基本文本示例" readonly> <button class="clipboard-btn" data-clipboard-text="这是一个要复制的基本文本示例"> <i class="bi bi-clipboard"></i> 复制 </button> // JavaScript const clipboard = new Clipboard('.clipboard-btn'); clipboard.on('success', function(e) { console.log('复制成功:', e.text); e.trigger.classList.add('copied'); }); clipboard.on('error', function(e) { console.error('复制失败:', e.error); });

复制目标元素内容

从页面上的其他元素复制内容，通过 data-clipboard-target 属性指定目标元素。

要复制的卡片标题

这是卡片中的内容，可以通过下面的按钮复制整个卡片的内容。

包括标题、内容和这个小字部分。

// HTML
<div id="targetElement">
    <h5>要复制的卡片标题</h5>
    <p>这是卡片中的内容...</p>
</div>

<button data-clipboard-target="#targetElement">
    复制卡片内容
</button>

<button data-clipboard-target="#targetElement h5">
    仅复制标题
</button>
// HTML <div id="targetElement"> <h5>要复制的卡片标题</h5> <p>这是卡片中的内容...</p> </div> <button data-clipboard-target="#targetElement"> 复制卡片内容 </button> <button data-clipboard-target="#targetElement h5"> 仅复制标题 </button>

剪切操作

剪切操作会复制内容并清空源元素。注意：某些浏览器可能不支持剪切操作。

剪切操作需要浏览器支持，某些浏览器可能有限制。 
// HTML
<textarea id="cutTextarea">这是一段可以被剪切的内容...</textarea>
<button data-clipboard-target="#cutTextarea" data-clipboard-action="cut">
    <i class="bi bi-scissors"></i> 剪切内容
</button>

// JavaScript
const clipboard = new Clipboard('button', {
    action: function(trigger) {
        // 也可以通过函数返回操作类型
        return 'cut';
    }
});
// HTML <textarea id="cutTextarea">这是一段可以被剪切的内容...</textarea> <button data-clipboard-target="#cutTextarea" data-clipboard-action="cut"> <i class="bi bi-scissors"></i> 剪切内容 </button> // JavaScript const clipboard = new Clipboard('button', { action: function(trigger) { // 也可以通过函数返回操作类型 return 'cut'; } });

事件处理

优化版 Clipboard.js 提供完整的事件系统，可以监听复制成功或失败事件。

事件将在这里显示...
// 事件处理示例
const clipboard = new Clipboard('.clipboard-btn');

// 成功事件
clipboard.on('success', function(e) {
    console.log('复制成功!');
    console.log('操作类型:', e.action);
    console.log('复制内容:', e.text);
    console.log('触发元素:', e.trigger);
    console.log('时间戳:', e.timestamp);
    
    // 添加成功样式
    e.trigger.classList.add('copied');
    
    // 2秒后移除样式
    setTimeout(() => {
        e.trigger.classList.remove('copied');
    }, 2000);
    
    // 清除选择
    e.clearSelection && e.clearSelection();
});

// 错误事件
clipboard.on('error', function(e) {
    console.error('复制失败!');
    console.error('错误信息:', e.error);
    
    // 显示错误提示
    alert('复制失败，请检查浏览器权限设置或手动复制。');
});
// 事件处理示例 const clipboard = new Clipboard('.clipboard-btn'); // 成功事件 clipboard.on('success', function(e) { console.log('复制成功!'); console.log('操作类型:', e.action); console.log('复制内容:', e.text); console.log('触发元素:', e.trigger); console.log('时间戳:', e.timestamp); // 添加成功样式 e.trigger.classList.add('copied'); // 2秒后移除样式 setTimeout(() => { e.trigger.classList.remove('copied'); }, 2000); // 清除选择 e.clearSelection && e.clearSelection(); }); // 错误事件 clipboard.on('error', function(e) { console.error('复制失败!'); console.error('错误信息:', e.error); // 显示错误提示 alert('复制失败，请检查浏览器权限设置或手动复制。'); });

静态方法

无需实例化即可使用的静态方法，适合一次性复制操作。

// 静态方法示例

// 1. 静态复制
Clipboard.copy('要复制的文本')
    .then(success => {
        if (success) {
            console.log('静态复制成功');
        } else {
            console.error('静态复制失败');
        }
    });

// 2. 静态剪切
const targetElement = document.getElementById('myInput');
Clipboard.cut(targetElement)
    .then(success => {
        if (success) {
            console.log('静态剪切成功');
        }
    });

// 3. 检查支持
const isSupported = Clipboard.isSupported();
console.log('剪贴板操作支持:', isSupported);

const canCopy = Clipboard.isSupported('copy');
console.log('复制操作支持:', canCopy);

const canCut = Clipboard.isSupported('cut');
console.log('剪切操作支持:', canCut);

// 4. 获取支持的操作列表
const supportedActions = Clipboard.getSupportedActions();
console.log('支持的操作:', supportedActions);
// 静态方法示例 // 1. 静态复制 Clipboard.copy('要复制的文本') .then(success => { if (success) { console.log('静态复制成功'); } else { console.error('静态复制失败'); } }); // 2. 静态剪切 const targetElement = document.getElementById('myInput'); Clipboard.cut(targetElement) .then(success => { if (success) { console.log('静态剪切成功'); } }); // 3. 检查支持 const isSupported = Clipboard.isSupported(); console.log('剪贴板操作支持:', isSupported); const canCopy = Clipboard.isSupported('copy'); console.log('复制操作支持:', canCopy); const canCut = Clipboard.isSupported('cut'); console.log('剪切操作支持:', canCut); // 4. 获取支持的操作列表 const supportedActions = Clipboard.getSupportedActions(); console.log('支持的操作:', supportedActions);

功能特性

避免全选复制

使用 Range API 替代全选操作，避免在某些浏览器中出现系统复制提示框。

现代 API 优先

优先使用现代浏览器的 Clipboard API，提供更好的性能和安全性。

UMD 支持

支持 AMD、CommonJS、ES6 模块和全局变量，兼容各种开发环境。

事件驱动

完整的事件系统，可以监听成功、错误等事件，方便进行状态反馈。

无障碍支持

支持键盘操作和屏幕阅读器，符合无障碍设计规范。

Bootstrap 5 友好

与 Bootstrap 5 完美集成，可以直接使用 Bootstrap 的按钮和组件。

API 文档

方法/属性 描述 参数 返回值
new Clipboard(trigger, options) 构造函数，创建剪贴板实例 trigger: 触发器元素或选择器
options: 配置对象 		剪贴板实例
.copy(text) 复制文本到剪贴板 text: 要复制的文本 Promise<boolean>
.cut(target) 剪切元素内容到剪贴板 target: 要剪切的元素 Promise<boolean>
.on(event, callback) 绑定事件监听器 event: 事件名称
callback: 回调函数 		当前实例
.off(event, callback) 移除事件监听器 event: 事件名称
callback: 回调函数（可选） 		当前实例
.destroy() 销毁实例，清理事件监听 无 无
Clipboard.copy(text, options) 静态方法：复制文本 text: 要复制的文本
options: 配置对象（可选） 		Promise<boolean>
Clipboard.cut(target, options) 静态方法：剪切元素内容 target: 目标元素
options: 配置对象（可选） 		Promise<boolean>
Clipboard.isSupported(action) 静态方法：检查浏览器支持 action: 操作类型（可选） boolean
Clipboard.getSupportedActions() 静态方法：获取支持的操作列表 无 Array<string>
事件对象属性： 成功和错误事件回调函数接收一个事件对象，包含以下属性： action（操作类型）、text（复制内容）、trigger（触发元素）、 success（是否成功）、timestamp（时间戳）、error（错误对象，仅错误事件）。
