Clipboard 组件演示

项目内置的剪贴板工具（statics/libs/clipboard/clipboard.js）： 支持选择器绑定与事件委托、文本/目标元素两种数据源、多策略写入（HTTP 与 iframe 可用），并提供成功/失败事件。

正在检测运行环境…

1. 复制固定文本

按钮上写 data-clipboard-text，初始化一次即可。
点击后到任意输入框粘贴验证 
<button class="demo-copy" data-clipboard-text="WiseAdmin · Clipboard 组件">复制文本</button>

<script>
new Clipboard(document, { delegate: '.demo-copy' });
</script>

2. 复制目标元素内容

用 data-clipboard-target 指向选择器。输入框取 value， 普通元素取 textContent。
composer require wiseadmin/wise-support
<input id="targetInput" value="https://...">
<button data-clipboard-target="#targetInput">复制</button>

<div id="targetCode">composer require ...</div>
<button data-clipboard-target="#targetCode">复制</button>

3. 事件委托（动态元素也能复制）

普通模式在初始化时逐个绑定按钮，节点被重建后就会失效；用 delegate 只在容器上挂一个监听，后插入的按钮同样生效。
插入后直接点击，无需重新初始化 
// 容器上只挂一个监听，动态节点也能命中
const clipboard = new Clipboard(document, {
    delegate: '.demo-copy'
});

4. 用函数决定复制内容

text 传函数时，参数是触发元素，可以按业务规则实时取值。 
const fnClipboard = new Clipboard('#fnCopyBtn', {
    text: function (trigger) {
        return document.getElementById('fnInput').value;
    }
});

5. 剪切

data-clipboard-action="cut" 会复制并清空目标输入框。 仅对 input/textarea 或 contenteditable 元素有效。 
<textarea id="cutInput">...</textarea>
<button data-clipboard-target="#cutInput" data-clipboard-action="cut">剪切</button>

6. 静态方法

只需要复制一段字符串时，用 Clipboard.copy()，无需创建实例。 
Clipboard.copy('要复制的内容').then(function (ok) {
    console.log(ok ? '成功' : '失败');
});

// 支持检测
Clipboard.isSupported('copy');        // true / false
Clipboard.getSupportedActions();      // ['copy', 'cut']

7. 事件与反馈

实例触发 success / error 事件，事件对象包含 action、text、trigger、timestamp， 失败时还有 error。下面的按钮都会写入日志。
window.__clipboardDebug 尚未产生
等待操作…
const clipboard = new Clipboard(document, { delegate: '.demo-copy' });

clipboard.on('success', function (e) {
    e.trigger.classList.add('copied');
    setTimeout(function () { e.trigger.classList.remove('copied'); }, 1500);
});

clipboard.on('error', function (e) {
    console.warn('复制失败', e.error || e);
});

8. API 速查

成员 说明
new Clipboard(trigger, options) 创建实例。trigger 可以是选择器、元素、NodeList；配合 options.delegate 时作容器。
options.delegate 事件委托选择器，如 '.copy-btn'；动态节点同样生效，推荐优先使用。
options.text 字符串或函数（参数为触发元素），自定义要复制的内容。
options.target 目标元素/选择器/函数，等价于按钮上的 data-clipboard-target。
options.action 'copy'（默认）或 'cut'；也可用按钮上的 data-clipboard-action。
instance.copy(text) / cut(target) 直接写文本 / 剪切元素内容，返回 Promise<boolean>。
instance.on(...) / off(...) / destroy() 事件订阅、取消订阅、销毁实例（委托监听会一并移除）。
Clipboard.copy(text) 静态写入，返回 Promise<boolean>。
Clipboard.isSupported(action) 检测 copy / cut 是否可用（现代 Clipboard API 或 execCommand）。
Clipboard.getSupportedActions() 返回可用操作数组。

9. 环境说明

  • 写入顺序：execCommand → copy 事件 → 顶层文档 → navigator.clipboard（仅 HTTPS/localhost）。
  • 后台页面通常在同源 iframe 中：HTTP 下子框架的写入可能被浏览器静默丢弃，因此组件会在顶层文档再写一次。
  • HTTP 非安全上下文中 navigator.clipboard 不可用，依靠 execCommand；仍失败时请检查浏览器剪贴板权限。
  • 诊断：每次写入后会记录 window.__clipboardDebug（含尝试顺序与命中的策略），失败时控制台会输出 [Clipboard] 写入失败。
