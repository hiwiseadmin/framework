API 参考

配置选项
参数说明
selectsselect 元素 ID 数组，至少两个
dataSource数据源：数组/函数/URL字符串
options.placeholder占位提示文本
options.parentField父级字段名，默认 "parent_id"
options.valueField值字段名，默认 "id"
options.labelField显示字段名，默认 "name"
options.loadingText加载中文本
options.errorText加载失败文本
实例方法
  • getValues() - 获取所有级别选中值
  • reset() - 重置所有选择
  • destroy() - 销毁实例
自定义事件
  • linkageSelectChange - 选择变化事件（在第一个 select 上触发）
