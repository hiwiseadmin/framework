WsUpload 文件上传组件

基于 jQuery + Bootstrap 5 的功能丰富文件上传组件

1. 三种主题样式

default 主题
drag 拖拽主题
minimal 简约主题
compact 紧凑列表（listLayout:'compact'）
mini-queue 迷你上传队列（listLayout:'mini-queue'）

2. 图片上传 & 网格预览

仅允许图片，自动生成缩略图预览，支持大图查看

3. 多文件 & 手动上传

支持多选、手动触发上传、文件限制

4. 类型/大小限制 & 自定义数据

限制文档类型、大小、最大文件数、添加额外数据

5. 拖拽 + 预览

拖拽上传 + 列表预览 + 统计信息

6. API 方法控制

API 输出将显示在这里...

主要配置项速查

参数类型默认值说明
urlString''上传接口 URL
multipleBooleanfalse多文件上传
acceptString'file'文件类型：images/video/audio/document/archive/file/custom
extsString''允许扩展名，逗号分隔
maxSizeNumber0最大文件大小(字节)，0不限制
maxFilesNumber0最大文件数，0不限制
autoUploadBooleantrue选择后自动上传
themeString'default'主题：default/drag/minimal
previewTypeString'list'预览类型：list/grid
parallelUploadsNumber3并行上传数
retryAttemptsNumber3失败重试次数
