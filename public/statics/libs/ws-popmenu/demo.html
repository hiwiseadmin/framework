WsPopMenu 组件演示

基于 jQuery、Bootstrap 和 Bootstrap Icons 开发的弹出菜单组件

组件特性：
  • 支持多种触发方式：点击、悬停、右键菜单
  • 灵活的定位选项（8个方向）
  • 支持多级嵌套菜单（无限级）
  • 内置 Bootstrap Icons 支持
  • 响应式设计，自动边界检测
  • 无障碍访问支持
  • UMD 模块封装，支持多种环境
  • 丰富的配置选项和事件回调

基本用法

展示三种基本触发方式的菜单：点击触发、悬停触发和带图标的菜单。 

// 点击触发菜单
$('#basic-click').wsPopMenu({
    items: [
        { text: '编辑', icon: 'bi-pencil', id: 'edit' },
        { text: '复制', icon: 'bi-copy', id: 'copy' },
        { text: '删除', icon: 'bi-trash', id: 'delete' }
    ]
});

// 悬停触发菜单
$('#basic-hover').wsPopMenu({
    trigger: 'hover',
    items: [
        { text: '首页', icon: 'bi-house', id: 'home' },
        { text: '个人资料', icon: 'bi-person', id: 'profile' }
    ]
});

定位示例

展示不同位置的菜单，支持 top、bottom、left、right 四个主方向，每个方向还有 -start、-end 变体。 

// 上方定位
$('#placement-top').wsPopMenu({
    placement: 'top-start',
    items: [...]
});

// 右侧定位
$('#placement-right').wsPopMenu({
    placement: 'right-start',
    items: [...]
});

右键菜单

在此区域点击右键查看右键菜单效果

支持所有桌面浏览器和移动设备的长按操作
右键菜单（上下文菜单）功能，支持自定义菜单项和事件处理。 

// 右键菜单
$('#contextmenu-area').wsPopMenu({
    trigger: 'contextmenu',
    items: [
        { text: '查看源代码', icon: 'bi-code', id: 'view-source' },
        { text: '检查元素', icon: 'bi-bug', id: 'inspect' },
        { type: 'divider' },
        { text: '刷新', icon: 'bi-arrow-clockwise', id: 'refresh' }
    ],
    onItemClick: function(id, $item) {
        console.log('右键菜单项:', id);
        alert('执行了操作: ' + id);
    }
});

二级菜单

支持多级嵌套菜单，可以无限级嵌套（但建议不超过3级以获得最佳用户体验）。 

// 二级菜单
$('#submenu-demo').wsPopMenu({
    items: [
        { 
            text: '文件', 
            icon: 'bi-folder', 
            id: 'file',
            children: [
                { text: '新建', icon: 'bi-plus', id: 'new' },
                { text: '打开', icon: 'bi-folder-open', id: 'open' },
                { 
                    text: '导出为', 
                    id: 'export-as',
                    children: [  // 三级菜单
                        { text: 'PDF', id: 'pdf' },
                        { text: 'Word', id: 'word' }
                    ]
                }
            ]
        }
    ]
});

动态内容

演示如何动态更新菜单内容和配置选项。 

// 获取菜单实例并更新内容
var menu = $('#dynamic-menu').data('wsPopmenu');
menu.updateItems([
    { text: '新菜单项 1', id: 'new1' },
    { text: '新菜单项 2', id: 'new2' }
]);

// 更新配置选项
menu.updateOptions({
    placement: 'bottom-end',
    offsetX: 10
});

API 文档

配置选项
选项 类型 默认值 说明
trigger string 'click' 触发方式：'click', 'hover', 'contextmenu'
placement string 'bottom-start' 菜单位置：top, bottom, left, right 及其 -start/-end 变体
items array [] 菜单项数组
offsetX number 0 水平偏移量（像素）
offsetY number 0 垂直偏移量（像素）
autoClose boolean true 点击外部是否自动关闭
菜单项格式
{
  text: '菜单文本',      // 必填
  icon: 'bi-icon-class', // 可选，Bootstrap Icons 类名
  id: 'item-id',         // 可选，用于标识
  disabled: false,       // 可选，是否禁用
  children: []           // 可选，子菜单项数组
}

// 特殊项
{ type: 'divider' }      // 分隔线
{ type: 'header', text: '标题' } // 分组标题
方法
  • .show() - 显示菜单
  • .hide() - 隐藏菜单
  • .toggle() - 切换菜单显示状态
  • .updateItems(items) - 更新菜单内容
  • .updateOptions(options) - 更新配置
  • .destroy() - 销毁菜单
事件回调
  • onShow() - 菜单显示时触发
  • onHide() - 菜单隐藏时触发
  • onItemClick(id, $item) - 点击菜单项时触发

使用说明

1. 引入依赖
<!-- jQuery -->
<script src="jquery.min.js"></script>
<!-- Bootstrap Icons (可选) -->
<link href="bootstrap-icons.css" rel="stylesheet">
2. 引入 WsPopMenu
<script src="popmenu.js"></script>
3. 初始化
// jQuery 插件方式
$('#element').wsPopMenu(options);

// 构造函数方式
var menu = new WsPopMenu(options);
menu.attachTo($('#element'));
