7. 配置选项说明

参数 类型 默认值 说明
containerElementdocument.body模态框挂载容器
initialColorString'#007bff'初始颜色，仅支持 #RRGGBB 格式
onColorChangeFunctionnull实时预览回调：任一颜色变化都会触发（拖动色相条/亮度/透明度滑块、拖动色盘、点击色块、HEX 输入、setColor() 等）；取消自动还原时也会触发一次。回调参数为当前颜色对象（结构见下），适合做拖拽实时预览
onColorSelectFunctionnull确认回调：仅当点击“确认选择”按钮时触发一次，参数为确认时的颜色对象；点 ✕/Esc/取消/遮罩关闭窗口不会触发它，如需区分“确认/取消”请使用 onClose（其 action 为 'confirm' / 'cancel'）
modalClassString'ws-color-picker-modal'模态框自定义 CSS 类名
modeString'default'弹窗布局：'default' 完整模式 / 'mini' 迷你模式（仅标准色+滑块+最近使用，图标化压缩）
standardColorsArray内置 32 色自定义标准调色板（#rrggbb 数组，非法值会被过滤）
storagePrefixString'ws-color-picker'最近使用/收藏的 localStorage 命名空间（改前缀可隔离）
maxRecentNumber8最近使用保留的最大条数
resetOnCancelBooleantrue取消(未点确认)关闭时是否把颜色还原为打开时的初始色
onCancelFunctionnull取消回调 (color, originalColor, { changed, lastColor })：仅取消(未确认)关闭时触发
onCloseFunctionnull关闭回调 ({ action, confirmed, originalColor, color, lastColor, changed })：任何关闭都会触发，action 为 'confirm'/'cancel'，用于区分用户是确认还是取消
回调参数 color 对象返回结构（onColorChange / onColorSelect / onCancel 的参数）
{
    hex: '#ff0000',           // HEX 颜色值
    rgb: 'rgb(255, 0, 0)',   // RGB 颜色值
    rgba: 'rgba(255,0,0,1)', // RGBA 颜色值（含透明度）
    hsl: 'hsl(0, 100%, 50%)', // HSL 颜色值
    hsla: 'hsla(0,100%,50%,1)', // HSLA 颜色值
    h: 0, s: 100, l: 50, a: 1  // 各通道独立值
}
API 方法
  • open() - 打开颜色选择器
  • close() - 关闭颜色选择器（等价于取消，触发 onClose action='cancel'）
  • setColor('#ff0000') - 设置当前颜色
  • getCurrentColor() - 获取当前颜色对象
  • destroy() - 销毁实例
